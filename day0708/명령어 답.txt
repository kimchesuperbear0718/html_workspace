특정 텍스트에 제목 효과를 내고 싶을 때	<h1> ~ <h6>	숫자가 작을수록 글자가 큽니다. (예: <h1>제목</h1>)
텍스트의 줄바꿈을 표현할 때	<br>	닫는 태그가 없는 줄바꿈 태그입니다.
텍스트를 두껍게 표현할 때	<b> 또는 <strong>	글씨를 굵게 만듭니다. (예: <b>두껍게</b>)
링크를 표현할 때	<a href="주소">	클릭하면 이동하는 링크입니다. (예: <a href="https://...">링크</a>)
수평선을 표현할 때	<hr>	화면에 가로 선을 긋습니다.
특정 텍스트 영역을 문단으로 묶고 싶을 때	<p>	문단(Paragraph)을 나눕니다. (예: <p>본문 내용</p>)
이미지를 삽입하고 싶을 때	<img src="이미지경로">	이미지를 넣는 태그입니다. (예: <img src="logo.png">)
순서 있는 목록을 표현하고 싶을 때	<ol>	1, 2, 3처럼 숫자가 붙는 목록입니다. 내부에 <li>를 씁니다.
순서 없는 목록을 표현하고 싶을 때	<ul>	점(●)으로 표현되는 목록입니다. 내부에 <li>를 씁니다.
버튼을 표현하고 싶을 때	<button>	클릭할 수 있는 버튼입니다. (예: <button>전송</button>)
체크 박스를 표현하고 싶을 때	<input type="checkbox">	네모난 체크박스를 만듭니다.
텍스트 입력 박스를 표현하고 싶을 때	<input type="text">	글자를 입력할 수 있는 하얀 한 줄 상자를 만듭니다.
옵션 선택 상자를 표현하고 싶을 때	<select>	클릭하면 아래로 선택지가 열리는 드롭다운 상자입니다. 내부에 <option>을 씁니다.
텍스트를 두껍고 동시에 이탤릭체로 표현할 때	<b><i> 또는 <strong><em>	두 태그를 겹쳐서 씁니다. (예: <b><i>텍스트</i></b>)
특정 텍스트를 흐르게 하는 전광판 효과를 내고 싶을 때	<marquee>	글자가 오른쪽에서 왼쪽으로 흐르게 만듭니다. (※ 현재는 잘 쓰이지 않는 오래된 태그이지만, 문제의 정답은 이것입니다.)
